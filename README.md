# CardGauge

A mobile-friendly Pokémon trading card pre-grading prototype.

## Run locally

Open `index.html` in a modern browser. No build step or API keys are required.

## Current features

- Upload or capture front and back photos of a Pokémon card.
- Experimental browser-based card centering inspection.
- Inspection feedback and downloadable text report.
- Responsive interface for phone or desktop.

## Limitations

This is **not** an official PSA grading service. It does not currently perform reliable automated corner, edge, or surface defect grading, nor does it authenticate cards or calculate market values. Card centering results are experimental and depend on image quality.

## Next steps

- Camera alignment and crop workflow.
- Defect review with zoomed views and manual correction.
- Calibrated predicted grade ranges with confidence measures.
- Optional Pokémon card identification and pricing integrations.
